# ClubNavi

## サイト概要

### サイトテーマ
クラブに行った人の口コミや5段階評価を投稿・検索できるレビューサイトです。

### テーマを選んだ理由
私はDJとして活動する中で、初めて行くクラブの雰囲気を事前に知りたい人がいると感じていました。一方で、クラブについて調べても、実際に行った人の感想を探しにくいことがあります。

そこで、利用者がクラブでの体験を投稿し、口コミや評価を確認できるサイトを作りたいと考えました。キーワードやタグから投稿を探せるようにすることで、自分に合ったクラブを選ぶ参考にできます。

DJとしての経験を生かし、クラブを初めて利用する人にも役立つ情報を共有したいと考え、このテーマを選びました。

### ターゲットユーザ
- 初めて行くクラブの雰囲気や評判を知りたい人
- 実際に行った人の口コミを参考にしたい人
- クラブでの体験を投稿したい人

### 主な利用シーン
- 行ったことのないクラブの口コミや評価を確認する時
- キーワードやタグから興味のある投稿を探す時
- 実際に行ったクラブの感想や評価を投稿する時
- 投稿にコメントして情報を交換する時
