# ClubNavi

## サイト概要

### サイトテーマ
クラブに行った人の口コミや5段階評価を共有できるレビューサイトです。

### テーマを選んだ理由
私はDJとして活動する中で、初めて行くクラブの雰囲気を事前に知りたい人がいると感じていました。一方で、クラブについて調べても、実際に行った人の感想を探しにくいことがあります。

そこで、利用者がクラブでの体験を投稿し、口コミや評価を確認できるサイトを作りたいと考えました。今後はキーワードやタグから投稿を探せる機能も追加し、自分に合ったクラブを選ぶ参考になるサービスを目指します。

### ターゲットユーザー
- 初めて行くクラブの雰囲気や評判を知りたい人
- 実際に行った人の口コミを参考にしたい人
- クラブでの体験を投稿したい人

### 主な利用シーン
- 行ったことのないクラブの口コミや評価を確認する時
- 実際に行ったクラブの感想や評価を投稿する時

## 1stデプロイ時点の主な機能
- 会員登録、ログイン、ログアウト、退会
- ゲストログインによる閲覧
- 口コミの投稿、一覧・詳細表示、編集、削除
- 投稿者以外による編集・削除の制限
- マイページ

## 今後追加する予定の機能
- キーワード・タグによる投稿検索
- 投稿へのコメント
- 管理者向けの会員・投稿管理
