# ClubNavi

## サイト概要

### サイトテーマ
クラブの基本情報や口コミを確認し、希望するクラブへゲスト申込ができるレビューサイトです。

### テーマを選んだ理由
私はDJとして活動する中で、お客様からのゲスト申込を受け付ける際、個別の連絡対応に手間がかかり、ゲストリストへの記入漏れが起きることに課題を感じていました。

また、お客様の立場でも、初めて行くクラブの雰囲気や評判が分からず、申込のために個別に連絡する負担があります。

そこで、クラブの情報や口コミを確認した上で、サイトから来店日と人数を指定してゲスト申込ができるようにします。クラブ側も申込内容を一覧で確認できれば、受付の負担や記入漏れを減らせると考えました。

こうした課題を解決し、クラブをより身近に楽しめるようにしたいと考え、このテーマを選びました。

### ターゲットユーザ
- 行ったことのないクラブの雰囲気や評判を確認したい人
- 自分に合ったクラブを探したい人
- クラブへのゲスト申込を簡単に行いたい人
- ゲスト申込をまとめて確認したいクラブ関係者

### 主な利用シーン
- 行ったことのないクラブの雰囲気や評判を調べたい時
- クラブの口コミを参考に行き先を探したい時
- 実際に行ったクラブの感想を投稿したい時
- 来店日と人数を指定してクラブへゲスト申込を行いたい時
- クラブ側がゲスト申込の一覧を確認したい時
