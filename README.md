# ClubNavi

## サイト概要

### サイトテーマ
クラブに行った人の口コミや5段階評価を共有できるレビューサイトです。

### テーマを選んだ理由
私はDJとして活動する中で、初めて行くクラブの雰囲気を事前に知りたい人がいると感じていました。一方で、クラブについて調べても、実際に行った人の感想を探しにくいことがあります。

そこで、利用者がクラブでの体験を投稿し、口コミや評価を確認できるサイトを作りたいと考えました。キーワードやタグから投稿を探せる機能も備え、自分に合ったクラブを選ぶ参考になるサービスを目指します。

### ターゲットユーザー
- 初めて行くクラブの雰囲気や評判を知りたい人
- 実際に行った人の口コミを参考にしたい人
- クラブでの体験を投稿したい人

### 主な利用シーン
- 行ったことのないクラブの口コミや評価を確認する時
- 実際に行ったクラブの感想や評価を投稿する時

## 主な機能
- 会員登録、ログイン、ログアウト、退会
- ゲストログインによる閲覧
- 口コミの投稿、一覧・詳細表示、編集、削除
- 投稿者以外による編集・削除の制限
- キーワード・タグによる投稿検索
- 口コミへの5段階評価
- 投稿へのコメント、本人によるコメント削除
- マイページ
- 会員名の部分一致検索、会員詳細での投稿一覧表示
- 管理者ログイン、会員一覧・詳細表示、会員削除
- Bootstrapによる画面装飾と画面幅に応じたレイアウト

## 設計書
画面遷移図、ER図、テーブル定義書を作成しています。

## 開発環境
- OS：macOS、Linux（Ubuntu）
- 言語：HTML、CSS、JavaScript、Ruby、SQL
- フレームワーク：Ruby on Rails
- データベース：MySQL（本番環境はAmazon RDSを使用）
- エディタ：Visual Studio Code
- デプロイ先：Amazon EC2
