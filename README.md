# ClubNavi

## サイト概要

### サイトテーマ
クラブの口コミやイベント情報を確認し、参加したいイベントへのゲスト申込ができるレビューサイトです。

### テーマを選んだ理由
私はDJとして活動する中で、お客様からのゲスト申込を受け付ける際、個別の連絡対応に手間がかかり、ゲストリストへの記入漏れが起きることに課題を感じていました。

また、お客様の立場でも、申込のためにやり取りをする負担や、連絡への返信がなく申込状況が分からないという不便さがあります。

そこで、サイト上でゲスト申込と申込状況の確認ができれば、受付側とお客様の双方の負担を減らし、記入漏れの防止にもつながると考えました。

さらに、クラブの口コミやイベント情報を確認できることで、これまで知らなかったクラブの雰囲気を知り、足を運ぶきっかけになると考えています。

こうした課題を解決し、クラブをより身近に楽しめるようにしたいと考え、このテーマを選びました。

### ターゲットユーザ
- 行ったことのないクラブの雰囲気や評判を確認したい人
- 自分に合ったクラブやイベントを探したい人
- クラブイベントへのゲスト申込を簡単に行いたい人
- ゲスト申込をまとめて管理したいDJやクラブ関係者

### 主な利用シーン
- 行ったことのないクラブの雰囲気や評判を調べたい時
- 参加したいクラブイベントを探したい時
- 実際に行ったクラブの感想を投稿したい時
- イベントへのゲスト申込を行いたい時
- 自分のゲスト申込状況を確認したい時
